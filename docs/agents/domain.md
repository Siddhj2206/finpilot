# Domain Docs

This repository is single-context.

Before exploring a design or implementation, read:

1. root `CONTEXT.md`, if it exists; and
2. applicable decisions under `docs/adr/`, if they exist.

`CONTEXT.md` defines the vocabulary to use in issue titles, plans, and code
reviews. Record hard-to-reverse decisions as ADRs rather than silently
re-litigating them. If these documents do not exist yet, proceed without
creating placeholder content; the relevant grilling or domain-modeling work
creates them when a real decision is reached.

This is temporary Matt Pocock skill configuration for the Finpilot rewrite and
is not intended for an upstream contribution by default.
